🔄 FLOW (Autom ático)
═══════════════════════════════════════════════════════════════════════════

1. Cliente envía JSON:
   ws.send({"type": "LOGIN", "username": "...", "password": "...", ...})

2. Backend construye binario 0x6102 y envía a Game Server

3. Game Server responde 0xa102

4. Backend parsea automáticamente con LoginHandler

5. Cliente recibe JSON con datos parseados:
   {"type": "STATUS", "status": "LOGIN_OK", "detail": {...}}

6. Cliente solicita CHARACTER_LIST

7. Backend procesa 0xb007 y envía personajes

8. Cliente selecciona personaje

9. Game Server confirma con 0xb001

❌ PROBLEMAS COMUNES
═══════════════════════════════════════════════════════════════════════════

"WebSocket no conectado"
  → npm run dev en blackrosebackend para iniciar gateway

"Conexión rechazada en 26.74.212.246:15882"
  → Firewall bloqueando TCP outbound, o IP/puerto incorrecto

"Login fallido"
  → Username/password incorrecto o servidor rechaza

"Personajes no recibidos"
  → Verifica que handleCharacterList() sea ejecutado en TcpSession.js

¿Cómo adicionar más opcodes?

1. Ver estructura en repo GitHub:
   • svalencius/silkroad-bot
   • leolongvu/SilkroadLeoBot

2. Agregar en OPCODE_DEFINITIONS.js:
   export function parseOpcode(buffer, opcodeHex) {
     if (opcodeHex === '0xNEWW') {
       return { /* estructura */ };
     }
   }

3. Procesar en TcpSession.js:
   if (packetObj.opcode === '0xNEWW') {
     this.handleNewOpcodeType(packetObj, session);
   }

4. Enviar JSON al cliente vía WebSocket
